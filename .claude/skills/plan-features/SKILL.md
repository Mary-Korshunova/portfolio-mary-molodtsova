---
name: plan-features
description: По брифу docs/SPEC.md выбрать стек и составить подробный feature_list.json — разовая инициализирующая сессия.
---

1. Прочитай `docs/SPEC.md`. Задай Мэри вопросы по пустым или неясным пунктам (не больше 5 за раз).
2. Предложи стек с объяснением простым языком (по умолчанию для сайта-визитки/лендинга — Astro или
   чистый HTML/CSS; для интерактивного приложения — Vite + React). Дождись согласия.
3. Разверни выбранный стек в корне проекта, обнови `init.sh`, `.claude/launch.json` (порт) и раздел
   «Стек» в `CLAUDE.md`.
4. Разбей сайт на 20–60 мелких проверяемых фич в `feature_list.json` (категории: foundation, layout,
   page, content, interaction, responsive, seo, a11y, performance, deploy). У каждой — `steps`,
   по которым её можно проверить в браузере, и `passes: false`. Существующие фичи не трогай.
5. Покажи Мэри сводку списка, запиши сессию в `claude-progress.md`, закоммить.
