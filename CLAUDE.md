# Проект: сайт

Долгосрочная работа над сайтом в течение многих сессий. Среда построена по методологии Anthropic
для долгоработающих агентов («Effective harnesses for long-running agents»): каждая сессия
начинается с нуля по памяти, поэтому всё состояние живёт в файлах и в git.

## Ключевые файлы

| Файл | Назначение |
|------|-----------|
| `docs/SPEC.md` | Бриф сайта: цели, аудитория, страницы, стиль. Источник истины о том, *что* строим. |
| `feature_list.json` | Список фич с критериями проверки. Меняется только поле `passes` (и `notes`). |
| `claude-progress.md` | Журнал сессий: что сделано, что сломано, что дальше. Новые записи — сверху. |
| `init.sh` | Запуск dev-сервера одной командой. |
| `src/` | Код сайта. |

## Ритуал начала сессии (`/start-session`)

1. `pwd` — убедиться, что мы в корне проекта.
2. Прочитать `claude-progress.md` (последние 2–3 записи) и `git log --oneline -20`.
3. Прочитать `feature_list.json`, выбрать **одну** фичу с наивысшим приоритетом и `"passes": false`.
4. Запустить `init.sh` (или preview `site` из `.claude/launch.json`) и проверить, что сайт открывается
   и уже сделанные фичи не сломаны. Если что-то сломано — сначала чинить это.

## Правила работы

- **Одна фича за раз.** Не начинать следующую, пока текущая не доведена и не закоммичена.
- **Проверять как пользователь.** Фича считается готовой только после проверки в браузере
  (built-in browser: открыть страницу, кликнуть, посмотреть на мобильной ширине 375px).
  Юнит-тест или «код выглядит правильно» — недостаточно.
- **Не удалять и не переписывать фичи** в `feature_list.json`. Можно только ставить `passes: true`
  и дописывать `notes`. Новые фичи — добавлять в конец, после согласования с Мэри.
- **Оставлять чистое состояние.** В конце сессии код рабочий, всё закоммичено, прогресс записан —
  следующая сессия должна стартовать без раскопок.
- Коммитить маленькими осмысленными шагами; сообщения коммитов на русском, в повелительном виде
  («Добавь шапку сайта»).

## Ритуал конца сессии (`/end-session`)

1. Убедиться, что сайт запускается и нет ошибок в консоли браузера.
2. Обновить `passes` у проверенных фич.
3. Добавить запись в начало `claude-progress.md`.
4. `git add -A && git commit`.
