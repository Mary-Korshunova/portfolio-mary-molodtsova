## О проекте

С помощью Claude Code я собрала прототип бизнес-ассистента Катюши для демонстрации на Финополисе. В MAX ассистент помогает предпринимателю открыть счёт, ведя его по понятному диалоговому сценарию.

В прототипе проработаны два пути: быстрое открытие счёта для действующих клиентов банка розничного направления и оформление для новых клиентов. Для обоих сценариев подготовлены адаптивные интерфейсы.
